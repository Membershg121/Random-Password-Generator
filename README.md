# Random Password Generator

**Автор:** Артем Марус

## Описание

Приложение с графическим интерфейсом для генерации случайных паролей с возможностью настройки длины и типов символов. Поддерживает сохранение истории сгенерированных паролей в JSON-файл, загрузку истории при запуске, копирование пароля в буфер обмена и оценку сложности пароля.

## Функциональность

- Ползунок выбора длины пароля (от 4 до 32 символов)
- Выбор типов символов:
  - Цифры (0-9)
  - Буквы (A-Z, a-z)
  - Специальные символы (!@#$%^&*()_+-=[]{}|;:,.<>?)
- Генерация случайного пароля по заданным параметрам
- Отображение сложности пароля (слабый / средний / сильный)
- Копирование пароля в буфер обмена
- История последних 50 паролей с датой и временем генерации
- Сохранение истории в файл `history.json` (автоматическая загрузка при запуске)
- Очистка истории
